# MOHRS-XBERecomp 0.1.2 (preview)

Improves performance at high frame rates by removing a CPU bottleneck in vertex processing. Packed vertex
streams now use the renderer's existing GPU decoding instead of converting every attribute to floats on the CPU.
The change applies to both single-player and co-op.

## Performance

In matched mission 1_3 opening-scene benchmarks at 2560x1440, 100% render scale and FoV 90 on an RTX 4090:

- Uncapped throughput increased from **290 to 450 FPS**, approximately **55%**.
- CPU vertex assembly fell from **1.49 ms to 0.30 ms per frame**.
- Present intervals exceeding the 240 FPS budget (4.17 ms) fell from **1.51% to 0.08%**.
- A separate run capped at 240 FPS reported **239-240 FPS** after loading.

These are short, repeatable scene benchmarks, not a guarantee of 240 FPS throughout the campaign.

Per-draw profiling clock reads and atomic accounting are also skipped when performance diagnostics are disabled.
`XBE_PERF=1` now produces detailed performance logs in release builds, including frame-interval percentiles.

## Installing or updating

Download `MOHRS-XBERecomp.zip` and extract it into a writable folder. New installations need your own Xbox disc
image in `assets\`; the first start builds the game code from it. The download contains no game code or game data.

When updating, keep `hdd\` and `settings.toml`, and replace the release files. Keep both executables and the
`compiler` folder together. Windows 10/11 64-bit and Direct3D 12 are required.

## Validation and known limits

Both release executables build. Packed-vertex tests cover signed coordinates, independently packed streams,
indexed and sparse draws, quads and a protected-page boundary. Timing audits pass for both Xbox executables.
The co-op executable passed a short 1440p/240 FPS rendering smoke check.

The full campaign and two-controller co-op still need broader playtesting. Unlocked frame rates above 60 FPS
remain experimental. Please include the mission, settings and `logs\` output when reporting an issue.
