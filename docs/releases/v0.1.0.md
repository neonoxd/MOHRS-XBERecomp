# MOHRS-XBERecomp 0.1.0 (preview)

The first preview of an unofficial native PC port of the original Xbox version of **Medal of Honor: Rising Sun**,
statically recompiled from the game's own code. The download has no game code and no game data: put your own disc
image in `assets\` and the first start builds the game from it.

## What works

- Single player and the Two Player Campaign (co-op, split screen), with saves and profiles, menus, movies, music
  and sound
- Controllers, and keyboard and mouse with raw mouse look and rebindable keys (`settings.toml` `[keys]`)
- 16:9 widescreen with the view widened (Hor+), the HUD and menus kept in proportion
- 60 FPS, and an experimental unlocked frame rate with elapsed-time updates
- Adjustable field of view, render scale, display mode, FPS limit, VSync and an FPS counter
- **PC Options** in the game's own menus: Options in the main menu, Preferences in the pause screen
- Optional skipping of the intro movies and the level cutscenes

## Installing

1. Download `MOHRS-XBERecomp.zip` and unzip it somewhere you can write to (not Program Files).
2. Put your Xbox disc image (`.iso`, xiso or full redump) into the `assets` folder.
3. Start `MOHRS.exe`. The first start builds the game code from your disc image (a few minutes, once), then press
   Start.

Windows 10 or 11 64-bit and a Direct3D 12 graphics card are needed. `README.txt` in the zip has the controls and
every setting.

## Known limits

- This is a preview: the whole campaign has not been played through on the port yet, and the later levels (1_5,
  1_7, 1_8, 1_9) have not been checked.
- Network multiplayer and Xbox Live are not supported.
- Unlocked frame rates above 60 FPS are new; if something behaves differently, compare at 60 FPS and report it.
- The PC Options screen is in English in every language.

Please report problems with the log from `logs\`, and the dump from `CrashDumps\` after a crash.
